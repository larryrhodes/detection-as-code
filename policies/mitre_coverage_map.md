## Methodology

- All rules use **auditd EXECVE** log sources
- Sigma format for portability; deployed to Wazuh via `deploy_rules.py`
- Every rule has a paired Atomic Red Team test in `atomic-tests/linux/`
- Alerts validated against `expected_alert.json` via `alert_validator.py`
- Coverage map updated automatically by `scripts/generate_report.py`
